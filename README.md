# 🇧🇪 Cloud Native Belgium

Welcome to the GitHub space of **Cloud Native Belgium**, a community-driven meetup group focused on Cloud Native technologies, Kubernetes, CNCF projects, DevOps, and beyond.

We gather engineers, architects, students and technology enthusiasts who want to:
- Share knowledge
- Learn from real-world experiences
- Meet fellow cloud native builders
- Strengthen the Belgian tech ecosystem

## 🎤 Speaker Resources

We publish (only when the speaker agrees):
- Presentation slides (PDF/PPT)
- Live demo repositories
- Useful links and references

👉 Looking for the latest content?  

If you’ve presented at our meetup and want to share material:
- Create a Pull Request
- Or reach out via the community channels below

> **Tip for presenters:**  
Feel free to include a short intro, abstract, and your contact/social links.
